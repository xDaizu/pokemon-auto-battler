# Design references

Drop inspiration images (pngs/jpegs) here — mockups, screenshots of other
apps/games, mood-board material, whatever helps communicate the intended
look and feel. No naming convention required; just keep filenames
descriptive enough to know what each one is at a glance.

When you add an image, add a line to the index below so there's context for
what it's showing and why it's relevant — discussed further in
[DESIGN.md](../DESIGN.md).

## Index

- [p5t-website.png](p5t-website.png) — [Persona 5 Tactica](https://persona.atlus.com/p5t/)
  site. Target for bold/vibrant/artistic visual style.
- [persona-5-golden-website.png](persona-5-golden-website.png) — [Persona 5 Royal](https://persona.atlus.com/p5r/?lang=en)
  site. Counter-example: like the boldness, but skip the gold-foil/ornate
  styling — we want plain, flat colors instead.
- [p5-fonts.png](p5-fonts.png) — fan-made breakdown of the fonts used
  throughout P5R (regular text, tarot cards, main menus, etc.), with free/
  paid alternatives for each. Useful as a starting point for picking our own
  typography: bold, condensed, high-contrast display faces, mixed and swapped
  per-letter for hand-lettered menu titles.
